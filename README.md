# Marketplace API

## Описание проекта

Backend-приложение маркетплейса для перепродажи вещей между пользователями. Проект реализует REST API для регистрации и авторизации пользователей, управления объявлениями, комментариями и пользовательским профилем.

Проект разработан в рамках курсовой работы и оформлен как production-like backend‑сервис.

Реализованы:
- регистрация и авторизация пользователей;
- роли пользователей (USER / ADMIN);
- защита эндпоинтов и разграничение прав доступа;
- CRUD объявлений;
- комментарии к объявлениям;
- загрузка изображений (multipart/form-data);
- валидация входных данных;
- документация API (OpenAPI / Swagger);
- логирование.

---

## Технологический стек

- **Java 17**
- **Spring Boot**
- **Spring Web (REST)**
- **Spring Security** (Basic Authentication, роли)
- **Spring Data JPA**
- **Maven**
- **Swagger / OpenAPI 3.0**
- **Multipart File Upload** (изображения)

## Архитектура

Проект реализован по классической слоистой архитектуре:

- **Controller** — REST-контроллеры (`controller`)
- **Service** — бизнес-логика (`service`)
- **Repository** — работа с БД (`repository`)
- **DTO** — объекты передачи данных (`dto`)
- **Entity** — JPA-сущности (`entity`)

## Аутентификация и авторизация

Используется **Basic Authentication**.

### Роли пользователей
- `USER` — обычный пользователь
- `ADMIN` — администратор

### Ограничения доступа

- Редактирование и удаление объявлений и комментариев доступно:
    - администратору;
    - автору объявления/комментария.

## Запуск проекта

### Требования
- JDK 17+
- Maven

### Запуск
```bash
mvn spring-boot:run
```

По умолчанию приложение доступно по адресу:
```
http://localhost:3000
```

---

## Как протестировать

1. Запустить приложение
2. Зарегистрировать пользователя:
   ```http
   POST /register
   ```
3. Авторизоваться:
   ```http
   POST /login
   ```
4. Использовать защищённые эндпоинты с Basic Auth

Swagger UI (если подключён):
```
http://localhost:3000/swagger-ui.html
```

## API Документация

Проект содержит OpenAPI-спецификацию (`openapi.yaml`).

---

## Пользователи

### Получить данные авторизованного пользователя
`GET /users/me`

---

### Обновить данные пользователя
`PATCH /users/me`

---

### Обновить пароль
`POST /users/set_password`

---

### Обновить аватар пользователя
`PATCH /users/me/image`

---

## Авторизация и регистрация

### Регистрация
`POST /register`

---

### Авторизация
`POST /login`

---

## Объявления

### Получить все объявления
`GET /ads`

---

### Добавить объявление
`POST /ads`

Тип запроса: `multipart/form-data`

---

### Получить объявление по ID
`GET /ads/{id}`

---

### Обновить объявление
`PATCH /ads/{id}`

---

### Удалить объявление
`DELETE /ads/{id}`

---

### Объявления текущего пользователя
`GET /ads/me`

---

### Обновить изображение объявления
`PATCH /ads/{id}/image`

---

## Комментарии

### Получить комментарии объявления
`GET /ads/{id}/comments`

---

### Добавить комментарий
`POST /ads/{id}/comments`

---

### Обновить комментарий
`PATCH /ads/{adId}/comments/{commentId}`

---

### Удалить комментарий
`DELETE /ads/{adId}/comments/{commentId}`

---
